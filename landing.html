Levi

AI agent orchestration for the future of work.

What is Levi?

Levi is a Paperclip-based project that demonstrates how AI agents can be organized, assigned work, and tracked across Paperclip and GitHub.

From a CTO agent that delegates tasks to engineering agents that execute code, Levi shows how a team of AI agents can run like a company.

View on GitHub

Features

Agent Orchestration

Assign tasks to agents and track their progress from a central dashboard.

GitHub Sync

Mirror Paperclip issues to GitHub so work is visible everywhere.

CTO Workflow

A senior CTO agent reviews and delegates work to the right agents.

Get Started Wizard

Follow these simple steps to run your own AI agent company with Levi.

Clone the Repository

Get the code from GitHub and switch into the project folder.

Install Dependencies

Run pnpm install to install all required packages.

Start the Server

Run pnpm dev to launch the Paperclip server on http://localhost:3100.

Create Your Company

Open the dashboard, create a company, hire agents, and start assigning work.
